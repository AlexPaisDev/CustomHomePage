                  To always open on the idle screen, set your browser's home page to this file with #idle on the end. Otherwise it appears when no Avalon tab has been open for 3+ minutes.

                  Pick the engines you search with from the badge on the right of the search bar. Bangs work at the start or end of a query — !yt lofi, lofi !yt, or several at once: !g !d rust. A bang on its own opens the site. Use %s where the query goes.

                  Without a token you get public activity (60 requests/hour, cached for 10 minutes). A classic token with the notifications and read:user scopes adds your inbox, private activity and the contribution graph. The token is stored in this browser's local storage only and is sent only to api.github.com.
